# 遂宁工程职业学院一站式学生工作智能平台

## 项目简介

遂宁工程职业学院一站式学生工作智能平台是面向高职院校的综合性学生工作管理系统，涵盖学籍管理、成绩管理、课表查询、考勤管理、奖助学金、宿舍管理、评优评先、第二课堂、毕业管理、就业服务、通知公告等11大核心模块。

**校训**: 厚德精技 · 求实创新

## 技术架构

### 后端技术栈
- **Java 17** + **Spring Boot 3.2**
- **MyBatis-Plus 3.5** (ORM框架)
- **MySQL 8.0** (数据库)
- **Redis 7** (缓存)
- **RabbitMQ** (消息队列)
- **Spring Security + JWT** (安全认证)
- **Knife4j** (API文档)

### 前端技术栈
- **Vue 3** + **Vite 5**
- **Element Plus** (UI组件库)
- **Pinia** (状态管理)
- **Vue Router 4** (路由)
- **Axios** (HTTP客户端)
- **ECharts** (图表)

| 评优评先 | 三好、优干、先进班集体评选 |
| 第二课堂 | 社团、志愿、实践、学分认定 |

| 通知公告 | 多级通知、回执统计、定时发布 |

## 核心业务规则

### 成绩计算
- 总评 = 平时×30% + 期中×20% + 期末×50%
- 绩点: ≥60分, 绩点=(成绩-50)/10; <60分, 绩点=0
- GPA = Σ(绩点×学分) / Σ学分

### 请假审批
- 事假≤1天: 辅导员批
- 事假1-3天: 院系批
- 事假>3天: 学工部批
- 病假(需医院证明): 3天内辅导员批
- 学期事假≤30天，考试周不批事假

### 奖学金
- 国家奖学金: ¥8000
- 国家励志奖学金: ¥5000
- 学院一等: ¥2000 / 二等: ¥1000 / 三等: ¥500
- 国奖与励志不可兼得

## 快速开始

### 环境要求
- JDK 17+
- MySQL 8.0+
- Redis 7+
- RabbitMQ 3.12+
- Node.js 18+

### 数据库初始化
```bash
mysql -u root -p < sql/init_database.sql
```

### 后端启动
```bash
cd backend
mvn clean package -DskipTests
java -jar target/student-platform-1.0.0.jar
```

### 前端启动
```bash
cd frontend
npm install
npm run dev
```

### 访问地址
- 前端: http://localhost:3000
- 后端API: http://localhost:8080/api
- API文档: http://localhost:8080/api/doc.html

## 数据库设计

- 表名规范: `sm_模块_表名`
- 字段规范: 小写下划线命名
- 审计字段: created_by, created_time, updated_by, updated_time, deleted
- 统一返回格式: `{ code, message, data, timestamp }`

## 接口规范

- 普通接口限流: 100次/分钟
- 批量接口限流: 10次/分钟
- 敏感操作需二次验证
- 所有操作记录日志
